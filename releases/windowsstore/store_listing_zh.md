# MediaBrain – Microsoft Store 产品详情 (简体中文)

## 产品名称
MediaBrain

## 简短描述 (最多 100 个字符)
本地隐私媒体库，用于管理视频、音乐、文档和流媒体播放历史。

## 完整描述
MediaBrain 是专为 Windows 打造的本地优先个人媒体管理中心。在一个清晰整洁的界面中统一整理和管理您的电影、剧集、音乐、播客、有声书及各类文档——完全支持离线运行，绝不向第三方服务器泄露任何数据。

轻松整合来自受支持流媒体服务、网页来源和本地文件夹的内容，自定义标签分类，按类型筛选，并通过内置的动态查询构建器创建个性化手动集合或全自动智能播放列表。

隐私安全至关重要：MediaBrain 不含任何遥测、用户分析或隐秘的云端同步。仅当您主动启用可选元数据抓取（例如 TMDb、OMDb 或 MusicBrainz）时，才会发起必要的网络请求。

## 核心功能
- 全能媒体库：支持视频、电影、剧集、音乐、播客、有声书与多格式文档
- 8 大模块化媒体源提供程序，支持自由切换可见性
- 自动文件监视与后台极速索引本地媒体目录
- 强大的智能播放列表，支持按分类、标签、评分与时长多重动态过滤
- 深度技术元数据检查器，完整展示音频、视频编解码器与封装信息
- 基于标准化 mediabrain-library-v1 JSON 格式的无损备份与多端还原
- 100% 本地运行、严格保护隐私、纯净无广告
