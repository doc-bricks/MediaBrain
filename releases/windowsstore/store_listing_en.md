# MediaBrain – Microsoft Store Product Listing (English)

## Product Name
MediaBrain

## Short Description (max. 100 characters)
Local-first, private media library for video, music, documents, and streaming history.

## Description
MediaBrain is your local-first personal media hub for Windows. Organize and manage movies, TV shows, music, podcasts, audiobooks, and documents in one clean, unified interface – completely offline-ready and strictly private.

Track streaming history from supported web sources and local folders, apply custom tags, filter by category, and create manual collections or dynamic smart playlists via the built-in QueryBuilder.

Privacy is paramount: MediaBrain contains no telemetry, no analytics, and no involuntary cloud synchronization. External connections only happen when you explicitly enable optional metadata fetchers (such as TMDb, OMDb, or MusicBrainz).

## Key Features
- Universal media management: Movies, TV series, music, podcasts, audiobooks, and documents
- Eight specialized media providers with customizable visibility
- Automated file monitoring and background indexing for local folders
- Dynamic Smart Playlists with multi-criteria filtering by category, tags, favorites, and runtime
- Comprehensive metadata inspector with deep technical audio and video codec insights
- Cross-platform backup and restore using the mediabrain-library-v1 JSON standard
- 100% offline-ready, private, and ad-free
