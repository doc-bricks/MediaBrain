# MediaBrain – Описание продукта в Microsoft Store (Русский)

## Название продукта
MediaBrain

## Краткое описание (макс. 100 символов)
Локальная медиатека для видео, музыки, документов и истории воспроизведения.

## Полное описание
MediaBrain — это персональный локальный медиацентр для Windows. Управляйте коллекцией фильмов, сериалов, музыки, подкастов, аудиокниг и документов в едином интерфейсе — полностью автономно и с абсолютным уважением к конфиденциальности данных.

Каталогизируйте материалы из поддерживаемых стриминговых сервисов, веб-источников и локальных каталогов, назначайте теги, фильтруйте по типам файлов и создавайте динамические «умные» плейлисты с помощью гибкого встроенного конструктора запросов.

Конфиденциальность превыше всего: MediaBrain не содержит телеметрии, скрытых трекеров и навязанной синхронизации с облаком. Внешние сетевые запросы выполняются исключительно по вашему прямому указанию — например, при включении поиска метаданных через TMDb, OMDb или MusicBrainz.

## Основные возможности
- Универсальное управление медиа: фильмы, сериалы, музыка, подкасты, аудиокниги и документы
- 8 модульных контент-провайдеров с возможностью индивидуальной настройки отображения
- Автоматический мониторинг папок и фоновая индексация локальных файлов
- Смарт-плейлисты с гибкой фильтрацией по категориям, тегам, оценкам и длительности
- Подробный инспектор метаданных с технической информацией о кодеках и контейнерах
- Экспорт и импорт библиотеки в открытом стандарте mediabrain-library-v1 JSON
- 100% локальное хранение данных, отсутствие рекламы и полная приватность
