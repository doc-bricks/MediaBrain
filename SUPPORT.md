# Support / Hilfe

## Deutsch

Für Fragen, Fehlerberichte und Funktionsvorschläge nutzen Sie bitte die
[GitHub Issues](https://github.com/doc-bricks/MediaBrain/issues) des Projekts.
Beschreiben Sie den Ablauf, das erwartete Ergebnis und das tatsächliche
Ergebnis. Hängen Sie keine Datenbanken, API-Schlüssel, persönlichen Medienpfade
oder Screenshots mit privaten Medieninformationen an.

Sicherheitslücken melden Sie bitte gemäß
[SECURITY.md](SECURITY.md) über GitHubs private Vulnerability-Reporting-Funktion
und nicht als öffentliches Issue.

## English

For questions, bug reports, and feature requests, please use the project's
[GitHub Issues](https://github.com/doc-bricks/MediaBrain/issues). Include the
steps, expected result, and actual result. Do not attach databases, API keys,
personal media paths, or screenshots containing private media information.

Please report security vulnerabilities through GitHub private vulnerability
reporting as described in [SECURITY.md](SECURITY.md), not in a public issue.
